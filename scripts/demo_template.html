Why two of them hold still

The equivariant network labels every internal feature by which irreducible representation of SO(3) it lives in, encodes bond directions as spherical harmonics, and combines features with Clebsch–Gordan tensor products — the operation that provably commutes with rotation. Interatomic distances feed a small network that weights those products, which is safe because a distance is already invariant. Only at the final readout are the invariant channels collected into a number.

The distance-only baseline gets invariance a blunter way: it never looks at direction at all. That works, but it cannot represent bond angles, which is the information the equivariant model keeps.

The naive network receives the raw components of each bond vector. Those three numbers change when you rotate the molecule, so its answer does too.

These networks are untrained

That is the point worth sitting with. No training, no data augmentation, random weights — and the drift is still zero to machine precision. Equivariance here is a property of the architecture, true for every possible setting of the weights, not something learned and approximately held. Absolute values are therefore arbitrary; what is being measured is how far each prediction moves.

Evaluated in float64 over a grid of orientations; the page interpolates between them. Drift is measured against the starting orientation. Source, derivations and the full test suite live in the SymmetryNet repository.
