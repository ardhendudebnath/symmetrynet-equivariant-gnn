A molecule’s properties cannot depend on how you happened to orient it when you wrote down the coordinates. Most networks learn that approximately, from augmented data. These are built so they cannot represent a function that violates it — and the representation theory behind that is implemented here from first principles, not imported.

072°  /  the headline

Equivariance wins — and it is not just angle-awareness.

Four models, one training loop, identical data and schedule. The third row is a control added late: invariant, but angle-aware. Without it, equivariance and angular information are confounded, because every equivariant model here also sees angles.

With that control in place, the advantage decomposes:

Angular information accounts for under a third of the gap. Equivariance contributes roughly two and a half times more, so it is not merely an expensive route to angles — the alternative explanation that could not previously be ruled out. Both models see the same angles; what differs is whether that information survives the next layer.

144°  /  scaling, not sample efficiency

The benefit compounds with data rather than shrinking.

The usual claim is that built-in symmetry buys sample efficiency: fewer examples for a given error, so the advantage should be largest when data is scarce. Measured across three seeds, the advantage moves the other way — and fitting the error curves says why.

Error follows a power law tightly here, MAE ∝ N^-b, with — on every fit. So the exponent is a real quantity, and the ratio of two power laws can only grow with N if the equivariant exponent is steeper. It is:

An offset advantage is a fixed discount; an exponent advantage compounds with every molecule added. So the honest statement is not that equivariance failed to deliver data efficiency, but that it improves scaling rather than sample efficiency — a different mechanism with the opposite signature.

216°  /  what each degree is worth

Higher angular resolution helps, then stops paying.

Inside one architecture, raising l_max monotonically improves accuracy. Yet PaiNN, which cannot represent anything above l=1, beats the tensor-product model at l_max=2. Measuring the channels directly resolves it: feature magnitudes are equal per component, but influence is not.

The prediction is far less sensitive to an l=2 component than to a scalar, while the Clebsch–Gordan paths that produce it cost roughly five times the compute.

l_max ablation

l_max=0 is the informative control: a fully equivariant model in which the selection rule permits no angular path at all.

288°  /  how it was built and checked

Derived by hand, verified against itself, and wrong several times.

The representation theory is implemented from first principles rather than imported, the symmetry claims are measured rather than asserted, and the mistakes along the way are kept in the write-up because they were the most instructive part.

Derived, not imported

Real spherical harmonics in closed form, Clebsch–Gordan coefficients from the Racah formula transformed into the real basis, and Wigner-D matrices built recursively from those coefficients — deliberately without touching the harmonics they are then used to verify, so the agreement is a genuine cross-check rather than a tautology.

1e-16 agreement with e3nn, in float64.

Verified, not asserted

259 tests. Symmetry checks run in float64 and are compared against the model’s own reproducibility floor, because CUDA scatter-add is non-deterministic and a tolerance below that floor measures nothing. Forces get stronger tests still: a field must rotate with the molecule, which zeros would also satisfy.

Wrong turns, kept in

A model that was exactly equivariant and silently underfitting, because activations compounded fourfold per layer. A tensor product that wanted 7.1 GiB for one forward pass. Constants baked at the wrong precision, inflating the residual a millionfold for higher degrees. Three convergence heuristics, each wrong in a different way.

Proving a network is equivariant proves nothing about whether it is trainable. The failure mode is silent.

360°  /  the obvious objection

Forces do not rescue the sample-efficiency claim either.

Everything above measures a scalar target, while the usual claim was made for tensorial ones. So the same comparison was run on MD17 forces — vector-valued, in the small-data regime where the claim originated.

Same direction as the scalar target. But this is the weaker experiment and is labelled as such: the equivariant model never actually wins here, only reaching parity, and it sits below its published capability — so the level of the curve probably understates it. One seed. Suggestive, not conclusive.
